Voortaan is React het standaard Web framework binnen AE Studio. Dit werd afgeklopt op onze TAF. Voortaan zal Vue dus de uitzondering zijn en enkel nog gebruikt worden als de klant er expliciet naar vraagt en er geen redenen zijn om React te verkiezen boven Vue.
 
Dit was een logische evolutie aangezien we React Native gebruiken als standaard app develoment framework, en zo ook al heel wat React kennis hebben opgedaan. React is daarnaast ook het FE framework met de grootste adoption rate én steun van grote bedrijven zoals Meta en Vercel.
 
Voor nieuwe projecten kunnen jullie reeds gebruik maken van de web-app-template-react, te vinden op https://dev.azure.com/aerepo/AE%20Templates/_git/web-app-template-react.
Deze code repo kan zowel als basis gebruikt worden voor SPA's als voor server side rendered applicaties (dmv NextJs).

Andere Sprint 0 code templates (zoals https://dev.azure.com/aerepo/AE%20Templates/_git/mobile-app-template-expo voor React Native based mobile apps) kan je steeds terugvinden op https://dev.azure.com/aerepo/AE%20Templates
